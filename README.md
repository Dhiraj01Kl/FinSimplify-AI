FinNews AI is an AI-powered platform that simplifies complex financial news into easy-to-understand summaries.

### Features
- Real-time financial news using NewsAPI.
- AI-powered news summarization.
- Simple explanations of financial terminology.
- Access to original news articles.
- User-friendly interface.

### Technologies Used
- Python
- FastAPI
- NewsAPI
- Groq API
- LLaMA 3.3 70B
- HTML, CSS, JavaScript

### Objective
To make financial news easier to understand and accessible to everyone using Artificial Intelligence.

### Project Domain
Artificial Intelligence | FinTech | Natural Language Processing
